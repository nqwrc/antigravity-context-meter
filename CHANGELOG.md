# Changelog

All notable changes to the ntigravity-context-meter extension will be documented in this file.

## [1.0.0] - 2026-08-27

### Added
- Initial release of Antigravity Context Window Meter.
- Real-time project-scoped status bar token counter.
- Reactive asynchronous file watching on session transcripts.
- Multi-window workspace-to-session disambiguation.
- QuickPick detailed inspection menu with turn and tool execution statistics.
- Direct shortcuts to open session transcripts and reveal artifact directories.
- Configurable warning thresholds and model context limits.
